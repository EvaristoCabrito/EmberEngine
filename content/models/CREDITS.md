# Créditos dos modelos e texturas de terceiros

Anotado para os créditos do jogo (o usuário, 2026-10-30: "pode marcar os créditos no projeto para depois"). O crédito vai para o
autor (não para o site): nome do autor, título, link e licença.

- **CC Attribution (CC BY 4.0):** crédito obrigatório. Exemplo: "Pine Forest at Sunset", de Jagobo
  (https://sketchfab.com/3d-models/pine-forest-at-sunset-bef89be6b189456095db79107045d726), CC BY 4.0.
- **Free Standard (Sketchfab):** uso comercial permitido, crédito não exigido, o arquivo cru não pode ser redistribuído.
- **CC0:** domínio público, crédito não exigido (listado aqui só para registro).
