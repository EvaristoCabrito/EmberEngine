Map background images

This folder is used directly by the editor and 3D gameplay.
Choose Imagem de fundo in the map editor and save the map. No selection means black void.

Add JPG, JPEG, PNG or WebP images with new filenames to preserve originals. New filenames appear after restarting the editor server (or rebuilding the application). Editing an existing image here updates that image after browser refresh. Keep original artwork and create separate versions for changes.
