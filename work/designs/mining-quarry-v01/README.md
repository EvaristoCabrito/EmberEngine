# Mineração e pedreira — propostas de construção

Cada prancha mostra três fases da esquerda para a direita: início da obra, etapa intermediária e construção concluída.

- `mine-level-1-construction-board-v01.png` — mina pequena, entrada de madeira e pedra.
- `mine-level-2-construction-board-v01.png` — mina ampliada com torre de içamento.
- `quarry-level-1-construction-board-v02.png` — pedreira pequena a céu aberto, com abrigo e guindaste manual.
- `quarry-level-2-construction-board-v01.png` — pedreira ampliada com corte em degraus, guindaste e área de corte.

Os arquivos são pranchas de conceito para revisão. Neste repositório encontrei modelos e adereços de mina, mas não encontrei um sistema de construções de assentamento com níveis e fases para cadastrar estas pranchas como construções ativas.
